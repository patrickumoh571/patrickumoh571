## 🧠 Engineering Principles

- **Correctness** — important rules belong on the server side
- **Idempotency** — retries must not create duplicate transactions
- **Traceability** — source and target documents remain linked
- **Security** — credentials and client data are never committed
- **Observability** — failures should be logged and recoverable
- **Reproducibility** — deployable customizations belong in source control
- **Business Value** — automation should improve control, visibility, and decision-making
